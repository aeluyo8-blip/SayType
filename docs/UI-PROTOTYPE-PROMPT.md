请为 Android 工具 App「phone-type」生成一套高保真 UI 原型图。

## 产品一句话

手机上用语音输入法说话 → 文字经局域网 WebSocket 发到电脑 → 电脑写入剪贴板并模拟 Ctrl+V，打到当前光标处。

## 全局设计系统（所有图必须一致）

- 画幅：完整手机机身（圆角、状态栏），逻辑分辨率约 390×844
- 风格：浅色为主；主色建议清爽蓝（或蓝紫一版）；禁止赛博朋克、霓虹、重拟物
- 卡片圆角 16–20dp；按钮层级：主按钮实心、次按钮描边/浅填充、文字按钮
- 中文文案清晰可读，不要错别字、不要乱码
- 同一套颜色、圆角、字号体系贯穿所有图

## 图 1A · 主界面 · 配置态（首次 / 未配好）

信息从上到下：

1. App 名：`phone-type`
2. 副标题：`手机说话成字，一键打到电脑光标处`
3. 状态卡片：
   - 灰点或空心点
   - 主文案：`未连接` 或 `悬浮窗权限未授予`
   - 副文案：`目标：—`
4. 配置区标题行：左侧 `连接配置`，右侧按钮 `扫码配置`（带小二维码图标）
5. 三个输入框：
   - `PC 局域网 IP`（placeholder `192.168.x.x`）
   - `端口`（默认 `8787`）
   - `PIN（PC 控制台显示）`（6 位数字）
6. 操作区：
   - 主按钮（实心、最大）：`启动悬浮球`
   - 次按钮：`连接 PC`
   - 一行两个次要按钮：`保存配置`、`悬浮窗权限`
   - 底部淡色文字按钮：`停止悬浮球`

要点：这是信息最全的一屏，但排版要有呼吸感，不要堆成表单墙。

## 图 2 · 悬浮球 · 自由态与贴边态

在同一部手机上叠一层「其他 App 内容」作背景（模糊的浏览器或社交界面即可），展示悬浮球浮在任意应用之上。

### 2A 自由态
- 屏幕右侧中部附近一个圆形悬浮球，直径约 56dp
- 球内：简洁的「文字/键盘」或「声波+文字」图标，白色
- 品牌色渐变填充，轻投影，有「可点、可拖」质感
- 旁注中文标签：`可拖动`、`点击展开输入`

### 2B 贴边收缩态（可同图分格或小图并列）
- 球贴到屏幕左边缘或右边缘后，变成半透明细长胶囊（约球宽的 1/3，略透明）
- 旁注：`贴边自动缩小`、`约 2 秒无操作后自动贴边`（若标注写不下，至少体现贴边后形态）

说明文案可用细线标注，不要盖住球本身。

## 图 3 · 输入面板（点悬浮球后）

- 面板浮在其他 App 之上，带阴影；背景 App 可轻微压暗
- 顶部：绿色圆点 + `已连接`；右侧 `收起`（或 ×）
- 中间：多行输入框，placeholder：`在这里用语音输入法说话…`
- 底部右侧：`清空`（文字/次按钮）+ `发送到电脑`（主色实心）

**互斥规则必须体现在图里**：面板打开时，屏幕上**不能**再看到悬浮球。

## 图 4 · 交互关系总览（可选，一张示意图）

用简单图示表达状态机，帮助理解：

```
启动悬浮球 → 球可见（自由）
    ├─ 拖到边缘松手 → 贴边收缩
    ├─ 约 2 秒无操作 → 自动贴边收缩
    ├─ 点贴边球 → 恢复完整球
    └─ 点完整球 → 打开输入面板（球隐藏）
输入面板
    ├─ 发送文字 → 电脑光标处出现文字
    └─ 收起 → 球恢复完整显示 → 约 2 秒后若无操作则自动贴边
```
