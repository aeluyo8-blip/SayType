# 厂商与系统坑

## Android

| 问题 | 处理 |
|------|------|
| 悬浮窗权限 | 设置 → 应用 → 特殊权限 → 显示在其他应用上层 |
| 小米/华为杀后台 | 自启动 + 电池无限制 + 后台弹出界面 |
| 前台服务通知 | Android 13+ 需 `POST_NOTIFICATIONS` |
| 键盘弹不出 | 输入弹层窗口不能带 `FLAG_NOT_FOCUSABLE` |

## Windows

| 问题 | 处理 |
|------|------|
| 粘贴无效 | 目标窗口若拒绝合成输入，降级为手动 Ctrl+V（剪贴板已写入） |
| 权限不足 | PC 服务与目标窗口权限需一致（管理员窗口要用管理员跑服务） |
| 同一 WiFi 才能连 | 手机填 PC 控制台打印的 `192.168.x.x` |
| PIN 每次重启变 | 也可用 `PHONE_TYPE_PIN=123456 npm start` 固定 |
